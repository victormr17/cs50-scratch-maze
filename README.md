# 🧩 Jogo do Labirinto - CS50x Project 0

Este projeto foi desenvolvido como parte do **Projeto 0 do curso CS50x da Universidade de Harvard**, obtendo a pontuação máxima nos requisitos de avaliação.

## 🎮 Como Jogar
- **Link do Jogo no Scratch:** [Clique aqui para jogar][https://scratch.mit.edu/projects/1385123740/]
- **Objetivo:** Atravessar o labirinto e alcançar a linha de chegada antes que o tempo esgote.
- **Controles:** Use as setas do teclado para movimentar o personagem.

## 🚀 Requisitos Implementados
- [x] Uso de múltiplos sprites e cenários customizados.
- [x] Bloco personalizado com parâmetro/input para abstração de movimentação e colisão.
- [x] Estruturas de repetição (`sempre`, `repita até`).
- [x] Condicionais para detecção de barreiras e vitória.
- [x] Controle de variáveis para o temporizador.

## 🛠️ Tecnologias Utilizadas
- Block-based programming via **Scratch 3.0**
